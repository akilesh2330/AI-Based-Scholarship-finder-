# 🎓 AI-Based Scholarship Finder

An intelligent, interactive, and responsive web application designed to help students discover eligible government and private scholarships across India based on their academic marks, family income, state, school, and social category.

🔗 **Live Repository:** [https://github.com/akilesh2330/AI-Based-Scholarship-finder-](https://github.com/akilesh2330/AI-Based-Scholarship-finder-)

---

## 🌟 Key Features

- **🎯 Smart Eligibility Matching:** Automatically evaluates eligibility criteria including annual income thresholds, minimum percentage marks, state restrictions, and category entitlements.
- **⚡ Instant Real-Time Results:** Dynamically filters and displays opportunities without page reloads.
- **📄 Document Checklist:** Highlights mandatory documents (such as Caste Certificates, Income Certificates, Marksheets, and Aadhaar) needed for each scholarship.
- **⏳ Application Deadlines & Status:** Displays active application deadlines and real-time status indicators.
- **💬 AI Support Integration:** Integrated live chat assistance via Tidio widget for interactive student guidance.
- **📱 Responsive & Modern UI:** Crafted with sleek glassmorphism, responsive grid layouts, and custom typography powered by Plus Jakarta Sans.

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akilesh2330/AI-Based-Scholarship-finder-.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd AI-Based-Scholarship-finder-
   ```

3. **Open `index.html`:**
   - Double-click `index.html` in your file explorer, or
   - Use an extension like [VS Code Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) to run a local dev server.
